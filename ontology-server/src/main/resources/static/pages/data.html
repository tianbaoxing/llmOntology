一、拓扑异常

孤立节点（无任何关系连接）

孤立节点通常意味着：LLM 抽取时只产生节点但未建立关联、或合并流程丢失了上下文关联。

自环关系（节点指向自身）

入度异常 Top 20（≥ 均值 + 3σ）

高度中心节点：可能是超级类（如「商代」被 1000+ 文物引用，属正常），也可能是 LLM 过度关联的错误 hub。

出度异常 Top 20（≥ 均值 + 3σ）
