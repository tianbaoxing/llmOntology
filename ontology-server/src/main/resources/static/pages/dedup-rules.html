❓ 什么是精确判重模式 / 冲突属性？（点击展开术语说明）
代码字段中文名解释
nameProp名称属性判重时取哪个属性当实体的「名字」
exactModes精确判重模式两个实体满足什么条件即判定为同一个，可多选
└ NAME_AUX名称+辅助属性名字规范化后相同，且辅助属性一致
auxProps辅助属性配合「名称+辅助属性」模式，防止同名误合并
conflictProps冲突属性值不一致 → 禁止自动合并，转人工确认
globalConflictProps全局冲突属性同上，对所有类生效
