自定义评测器

不写代码，用提示词定义 LLM 评测器，与内置评测器同等地位（可勾选运行、结果落盘、可回归对比）。两种模式：评分标准（默认）只写「怎么打分」，样本内容由框架固定区块隔离拼接（防提示词注入）；完整模板（进阶）可用五个占位符 {{query}}/{{answer}}/{{reference}}/{{context}}/{{rubric}}。先「试跑」验证判分效果再入库；保存后热生效，重启自动恢复

Skills 管理

展示系统已装配的技能：识别关键词由你填写该 skill 被真实执行时的特征词（逗号分隔），供后续判断 LLM 是否真正执行了它；执行脚本列出技能目录下可执行脚本（如 tongshu_query.py）；检测结果为工具（系统工具反向比对）/ API / Shell 命令统计，检测为手动触发并落盘 data/skill-analysis.json。技能文件变更后检测按钮变红并顶部提示，需重新检测。详情页中太常见的工具 / API / Shell 命令可点击 × 删除（忽略），忽略项跨重新检测保留并自动保存
