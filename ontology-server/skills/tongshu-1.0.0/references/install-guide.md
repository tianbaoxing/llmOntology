# 通书技能安装与校准指南

## 安装完成

通书技能已安装在 `/root/.hermes/skills/tongshu/`，包含：
- `SKILL.md` — 使用说明
- `scripts/tongshu_query.py` — 核心查询脚本

## 使用方式

直接让助手查："今天通书怎么样"、"查2026年端午节的通书"、"6月19号适合办事吗"

## 输出内容

- 干支（年柱、月柱以节气为准、日柱）
- 建除十二神（含释义和择日提示）
- 二十八宿（名称、四象、五行、吉凶）
- 彭祖百忌（天干10条+地支12条）
- 冲煞（冲什么生肖、煞什么方向）
