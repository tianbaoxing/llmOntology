# 通书每日神煞查询

## 使用方法

直接问我任意日期的通书信息即可。格式：

- "查2026年6月15日的通书"
- "今天通书怎么样"
- "查2026年端午节（五月初五）通书"

## 输出内容

每日包含：
1. **干支**：年柱、月柱（以节气为准）、日柱
2. **建除十二神**：建除满平定执破危成收开闭，含释义和择日建议
3. **二十八宿**：28宿名称、四象（青龙/玄武/白虎/朱雀）、五行、吉凶
4. **彭祖百忌**：天干+地支禁忌
5. **冲煞**：冲什么生肖、煞什么方向

## ⚠️ 校准要求

每年需要校准两个锚点：
1. **建除起始**：每年正月初一的建除位置（根据年支确定）
2. **二十八宿起始**：每年某已知日期对应的二十八宿位置（脚本中假设值，需查通书校准）

校准方法：查通书确认一天，更新脚本中的 `JIANCHU_YEAR_ANCHOR` 和 `ERSHUBU_YEAR_ANCHOR`。

**当前2026年二十八宿锚点已校准**：2026-06-22 丁卯日 = 觜宿（白虎·金·凶），脚本输出验证通过。但建除起始锚点仍需年度校准。

详见 `references/install-guide.md`。

## 建除十二神

建除满平定执破危成收开闭（12天循环）

每年正月初一起始位置由年支决定：
- 子/辰/申年 → 起建
- 丑/巳/酉年 → 起除  
- 寅/午/戌年 → 起满
- 卯/未/亥年 → 起平

## 二十八宿

角亢氐房心尾箕斗牛女虚危室壁奎娄胃昴毕觜参井鬼柳星张翼轸（28天循环）

## 彭祖百忌

内置天干10条+地支12条。

## 冲煞

基于日支推算：子午冲、丑未冲等，同时标注煞向。
